# Proyecto de Vida Personal

Aplicación web para gestionar el proyecto de vida personal, incluyendo metas, horario, prioridades, proyectos, certificaciones, plan de estudio y CV.

## Tecnologías
- HTML5, CSS3, JavaScript (Vanilla JS)
- Chart.js para gráficos
- Font Awesome para iconos
- Google Fonts para tipografías

## Estructura
- `index.html` - Página principal
- `css/` - Estilos modulares por sección
- `js/` - JavaScript modular por sección

## Ejecución
Abrir `index.html` en el navegador.
